AI読み取り（Claude API）
AI読み取りを使うと、撮影した写真（患者の氏名・病名・服薬など）が Anthropic 社のサーバーへ送信されます。 院内の個人情報の取扱い方針（利用目的の掲示など）と照らして、使ってよいか判断してから有効にしてください。 AIを使わなくても、手入力で文書の作成・印刷・保管はすべてできます。

API キーは Claude Console で発行します。Console で月の利用上限（Spend limit）を設定しておくと安心です。

保管

使い方

1. iPhone の Safari でこのページを開き、共有ボタン →「ホーム画面に追加」するとアプリのように使えます。ホーム画面から開くと保存データが消えにくくなります。

2. 「新規」で文書の種類を選び、紹介状やお薬手帳を撮影 →「AIで読み取って下書きを作成」。

3. 内容を確認・修正して「保存」。「印刷プレビュー」→「印刷」で AirPrint 印刷、または共有メニューから PDF 保存できます。

4. データはこの端末の中だけに保存されます。定期的に「保管一覧」→「バックアップ（JSON）」で書き出してください。

※ AI の読み取り結果は必ず原本と照合してください。【要確認】と付いた箇所は読み取りに自信がない部分です。
