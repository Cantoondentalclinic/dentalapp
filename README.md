# 院内アプリ

医院で使うアプリです。下のアドレスをブラウザ（Edge / Chrome / Safari）で開くと使えます。

| アプリ | 用途 | アドレス |
| --- | --- | --- |
| 🦷 **歯科自費管理** | 自費診療の管理、FAX 発注書の作成 | https://cantoondentalclinic.github.io/dentalapp/ |
| 📋 **老健訪問歯科健診表** | 訪問歯科健診の入力（オフライン対応） | https://cantoondentalclinic.github.io/dentalapp/kenshin/roken_checkup.html |
| 🛒 **院内物販** | 商品をタッチ → 注文票を印刷 | https://cantoondentalclinic.github.io/dentalapp/shop-kiosk/web/ |
| 🧾 **レシート一覧** | 保存したレシート・領収書をファイル名から一覧化・検索（電子帳簿保存法の検索用） | https://cantoondentalclinic.github.io/dentalapp/receipts/ |
| ✉️ **照会・返信文書** | 紹介状・お薬手帳を撮影 → 照会状・返信・紹介状を作成、印刷・保管・書き出し（iPhone 対応） | https://cantoondentalclinic.github.io/dentalapp/shokai/ |

## データについて

入力したデータは、開いた端末のブラウザの中にだけ保存されます。このページやサーバーには送られません。
端末を変えるときは、各アプリのバックアップ機能（歯科自費管理は「データ保存・同期」）を使ってください。

※ 照会・返信文書の「AI読み取り」を有効にした場合のみ、撮影した写真が AI（Anthropic 社の Claude API）へ送信されます。既定では無効です。
