🦷 技工指示書保管

入力者

手書きの技工指示書をスキャンして、技工所ごとにまとめて保存・検索します。
保存したファイルは 上書き・削除せず、修正は履歴として残し、改ざんがないかを点検できます。

ブラウザから確認が出たら「毎回許可する」を選ぶと、次回から開くだけで読み込みます。

・保存先は、パソコンに同期した Google ドライブのフォルダ（例：マイドライブ／技工指示書）や院内NASのフォルダを選んでください。ブラウザの中には保存しません。
・複数のパソコンで同じフォルダを開けば、院内で共有できます。
・パソコンの Chrome か Edge で使ってください（Safari・スマホはフォルダへの書き込みができません）。

このブラウザはフォルダへの保存に対応していません。パソコンの Google Chrome または Microsoft Edge で開いてください。

整合性チェック（改ざん・欠落の点検）

台帳の各記録はひとつ前の記録のハッシュ値（SHA-256）を含んで連結されており、指示書ファイルも登録時のハッシュ値と照合します。アプリの外でファイルや台帳が書き換えられたり消されたりすると、ここで検出されます。月に1回程度行ってください（結果も履歴に残ります）。

🤖 AI読み取り（手書き指示書の内容を自動入力）

スキャンした指示書の画像を Anthropic 社の AI（Claude）に送り、技工所・発行日・患者・技工物・部位などを読み取って入力欄に自動で入れます。技工所ごとに様式が違っても読み取れます。読み取りに自信がない項目は赤枠で示します。

個人情報について（有効にする前に必ずお読みください）
・指示書の画像（患者名などを含む）が、米国の事業者である Anthropic 社のサーバーに送られます。API で送ったデータは同社のAIの学習には使われない取扱いですが、一定期間（原則30日）同社で保管されます。
・個人情報保護法では「外国にある第三者」への提供にあたるため、①患者さんの同意を得る、または ②同社と個人データの取扱いに関する契約（DPA）を結ぶなど、日本と同等の保護の体制を確認する ことが必要です。あわせて院内掲示（下の「院内掲示」に文言が入ります）と、患者さんから求めがあったときの説明を行ってください。
・厚生労働省の「医療情報システムの安全管理に関するガイドライン」に沿い、外部サービスの利用として管理責任者が判断し、記録を残してください（有効にした人と日付は台帳に記録されます）。
このパソコンの設定（APIキーはこのパソコンのブラウザの中だけに保存し、保存フォルダには書きません）

API キーは Claude Console で作成します（利用料は使った分だけ Anthropic 社から請求されます）。キーを入れたパソコンは、院外の人が触れないように管理してください。

備え付ける書類（印刷して保管）

電子帳簿保存法のスキャナ保存では「事務処理規程」等の備付けが、厚生労働省のガイドラインでは運用管理規程や患者への周知が求められます。医院名・責任者を入れたひな形を作ります。内容は医院の運用に合わせて手直ししてください。
